Roar is a platform which enables citizens to ask questions and demand accountability from those elected.

Roar works like twitter - with basic differences...

the app - should be user deploy-able and have equal trust on the platform : based on something accountable : like aadhar/digital id.

The identity : is created as a pair of pub/private certs : generated on seeding aadhar.

the public key : should be stored on the network : and should be verifyable for official tasks / requests /complaints.

The platform is local and regional : where views and opinions are upvoted or downvoted ...depends on region/geo of user.
This upvote/downvote : is public and accountable which leads to ‘amplification’ of roar done by a citizen.

amplification : aims to be akin to escalation.

Roars : are and would be not time flowing : the irritating UI of scrolls...
but remain at ‘home’ : till the upvotes or the original roar-er : finds some opinion or resolution.

underlying tech - blockchain and distributed computing.

This is metaverse : as i see as ‘needed’ and ‘wanted’.

This would be my quest to counter X : what it is and what it slated to become.
